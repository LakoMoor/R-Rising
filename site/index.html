A V Rising runtime in Rust, with every claim measured.

R-Rising loads the game files from your own installation and rebuilds the engine around them. Native desktop and the browser run the same renderer. It is not playable yet, and this page says exactly how far it has got.

What it draws today

Real models and textures from a local installation. The scene views place entities at their original positions; there is no lighting, animation or gameplay, and some surfaces are still wrong.

The original is the specification

Behaviour is taken from the shipped game, not from guesses. Original functions are replayed to produce test data, original scene files serve as ground truth, and the results decide what counts as done.

Reading Unity data is kept apart from the GPU, so the browser build shares the renderer without the native file loader.

  1. Your game filesUnityFS archives, EntityScenes and the content catalog stay on your machine.
  2. Rust coreContent readers, then ECS and the scene world, then simulation.
  3. wgpuOne renderer for native Metal, Vulkan and DirectX, and for WebGPU in the browser.

Run it yourself

You need your own copy of V Rising. Rust 1.99.0 is pinned by the repository. There is no packaged release yet.

Native

Point it at the VRising_Data folder of your installation.

Terminal
git clone https://github.com/LakoMoor/R-Rising
cd R-Rising
cargo run --release --locked -p rrising-app -- \
  --data /path/to/VRising_Data
All options

Browser

Export a scene on your machine, then open the file in the viewer. The data never leaves your device.

Local export
cargo run --locked -p rrising-app -- \
  --data /path/to/VRising_Data \
  --export-web scene.rrscene.json \
  --archives 5000 --items 48 \
  --width 1600 --height 900
Open the WebGPU viewer

Needs WebGPU and BC texture support. Mobile and WebGL are untested.

What happens next

  1. Read and draw real content

    Archives, scenes and types are read; native and browser draw original scenes at their stored positions.

  2. Make the world run

    Transforms already reproduce 99.3% of the stored values; the rest is the exact original arithmetic, then systems, scheduling and the remaining component kinds.

  3. One playable scenario

    Tie input, simulation and display together and compare the result with the running original.

  4. Speed and devices

    Same-scene release timings against the original, texture fallbacks, and checks on other platforms.
