01 / СОВМЕСТИМОСТЬ

Что перенесено сейчас

Полный отчёт ↗

Раскройте подсистему: что реализовано, чем это проверено и чего ещё не хватает. У парсинга ресурсов и поведения игры разные критерии готовности.

01 Математика имена API97,8%+

Векторы, матрицы, кватернионы, RigidTransform и half. 4 850 из 4 961 имён членов метаданных сопоставлены с Rust-кодом.

Остаётся: проверка на оригинальном runtime, точный порядок вычислений, SIMD-приближения и оставшиеся перегрузки. Совпадение имени не доказывает совпадение результата.

02 ECS runtime имена API2,2%+

Базовые типы сущностей, описание компонентов, раскладка архетипов и чанков. Метрика обновляется из репозиторного отчёта: 184 из 8 486.

Остаётся: полноценное выделение сущностей, запросы, планирование систем и подключение оригинального мира к игровому циклу.

03 Архивы ресурсов проверено на файлах100%+

Все 4 409 UnityFS-архивов этой установки прочитаны. Проиндексировано 188 063 объекта: модели, текстуры, материалы и другие ресурсы.

Граница проверки: чтение файлов не означает правильную загрузку всех зависимостей или исполнение игровой логики. Файлы самой игры не поставляются.

04 Контейнеры EntityScenes проверено на файлах100%+

Разобраны 1 183 контейнера сцен: деревья узлов, архетипы, чанки, enabled masks, динамические буферы, shared/managed-компоненты и blob assets.

Остаётся: разрешить типы компонентов, восстановить живой ECS-мир и использовать его в обычном игровом запуске. Процент относится к парсингу.

05 Рендеринг и браузер рабочий срезviewer+

Один wgpu-рендерер и WGSL-шейдер используются в нативном приложении и WebAssembly. В Chrome проверен локальный экспорт сцены с 48 оригинальными объектами.

Остаётся: исходное размещение мира, HDRP, анимация, прямой импорт архивов в браузере и fallback текстур для мобильных GPU. Нужны WebGPU и BC compression.

06 Геймплей и 1:1 поведение впередине готово+

Бой, строительство, HUD, физика, звук, сеть и сохранения пока не реализованы. Сценариев сравнения с работающим оригиналом ещё нет.

Производительность: ускорение относительно оригинала не измерено. Это цель проекта, а не подтверждённый результат.

↳

Совместимость 1:1 пока неизвестна. Проценты API могут завышать покрытие из-за общих имён. Они не показывают, какую долю игры уже можно пройти. Открыть исходные метрики JSON.

03 / УСТРОЙСТВО ДВИЖКА

Оригинал — спецификация.

Цель R‑Rising — запускать реальный контент и воспроизводить поведение конкретной сборки игры. Работа идёт от форматов и детерминированного ядра к связанному игровому миру.

Чтение Unity-ресурсов отделено от GPU. Браузерный хост использует тот же рендерер через локальный перенос сцены, без нативного загрузчика библиотек.

04 / ПОПРОБОВАТЬ

Собрать. Открыть. Проверить.

Reference build: V Rising v1.1.13.0-r99712-b17, Unity 2022.3.58f1. В репозитории закреплён Rust 1.99.0. Готового игрового релиза пока нет.

NATIVE

Из исходников

Укажите папку VRising_Data вашей установленной игры.

TERMINAL
git clone https://github.com/LakoMoor/R-Rising
cd R-Rising
cargo run --release --locked -p rrising-app -- \
  --data /path/to/VRising_Data
Параметры запуска ↗
WEBASSEMBLY

В браузере

Сначала экспортируйте сцену локально, затем откройте файл в viewer. Данные остаются на вашем устройстве.

LOCAL EXPORT

  --data /path/to/VRising_Data \
  --export-web scene.rrscene.json \
  --archives 5000 --items 48 \
  --width 1600 --height 900
